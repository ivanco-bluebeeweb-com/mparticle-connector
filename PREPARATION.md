# mParticle Connector — Preparation

**Category:** C36. Customer Data Platform (CDP)  
**Vendor URL:** https://mparticle.com  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **mParticle** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C36. Customer Data Platform (CDP)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **мобильный разработчик** сталкивается с задачей: **кросс-платформенная оркестрация мобильных и веб-событий, единый профиль клиента и передача в партнерские сервисы**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор mParticle переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **мобильный разработчик, архитектор данных, CRM-маркетолог**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `получение подключенных фидов -> проверка правил маппинга данных -> валидация передачи событий в реальном времени`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса mParticle.
